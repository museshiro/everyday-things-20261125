## The entry

Line 1 explains a queue to a 10-year-old with one analogy: a queue is a train
made of people, where each carriage walks itself to the front. Line 2 is the
honest accounting: it says what the analogy maps (shuffling forward one
person at a time, the way carriages pass a platform one by one) and what it
leaves out (carriages can't get bored, buy a snack, or simply walk away).

## Run it

```sh
node main.ts
```

`main.ts` writes the two lines to `entry.txt` (and to `/output/entry.txt`
when that directory exists, for the grader sandbox).
